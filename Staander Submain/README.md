# Staander — MVP

Protótipo front-end navegável do conceito do Staander.

## Fluxo
Landing page → Quiz → Perfil/recomendação → Próximo passo.

## Como testar
Abra `index.html` no navegador.

## Próximos passos para transformar em MVP real
1. Definir catálogo/ofertas reais do Staander.
2. Transformar as respostas em regras de recomendação.
3. Conectar formulário/lead a um backend ou CRM.
4. Criar páginas reais para cada recomendação.
5. Medir início do quiz, conclusão, clique na recomendação e conversão.
