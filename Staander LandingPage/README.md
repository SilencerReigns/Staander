# Staander — Landing Page MVP

Landing page de apresentação e conversão do Staander. A estrutura considera o produto como uma biblioteca digital viva: organização, busca, leitura, continuidade, curadoria e camada de conhecimento. O material-base descreve como objetivo transformar arquivos dispersos em uma biblioteca pessoal acessível e fácil de manter, e destaca entrada sem atrito, biblioteca pesquisável, curadoria e progresso entre dispositivos.

Inclui: hero, problema, solução, espaços para vídeos, 3 estudos de caso, infográficos, comparativo, 3 espaços de social media, depoimentos/avaliações e CTA final.

Os números, comparativos e casos são placeholders. Substitua por evidências reais antes de publicar.

Abra index.html no navegador.
