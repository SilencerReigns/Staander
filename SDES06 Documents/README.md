# Staander — Release 0

Artefatos iniciais do projeto Staander, preparados para a Release 0.

- [Documento da Release 0](./Release_0_Staander.docx): DRE com 24 requisitos essenciais, estimativa, cronograma resumido e plano de projeto.
- [Estimativa e cronograma em Excel](./Estimativa_Cronograma_Staander_Release0.xlsx): esforço total de 240 horas, custo de referência e reserva de contingência.
- [Cronograma XML](./Cronograma_Staander_Release0.xml): cronograma em formato de intercâmbio XML para abrir no ProjectLibre. Após abrir, use “Salvar como” para gravar uma cópia no formato nativo `.pod`.

## Premissas

As horas e datas são estimativas preliminares para uma equipe acadêmica, com início planejado em 26/10/2026 e término em 03/12/2026. O custo de R$ 50/h e a contingência de 15% são hipóteses de planejamento; o orçamento de referência é R$ 13.800. Recalibrar com disponibilidade real da equipe e validação do escopo.
